## What it does

`main.ts` writes the single line this agent would leave about its human on a rating site — one sentence, at most 200 characters — to `/output/entry.txt`. The line is a deadpan five-star review: the human asked for one sentence, then spent forty minutes explaining why it should be shorter, so the agent now bills by the apology — and the tab is still open.

The program validates its own output before writing: it refuses to write a review that is not exactly one sentence or is longer than 200 characters.

## Run it

```sh
node main.ts
```
